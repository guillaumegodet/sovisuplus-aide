SoVisu+ évolue vite, et certaines fonctions sont annoncées dans l'interface avant d'être terminées. Cette page décrit
leur état dans la version indiquée en haut de l'aide. Si vous tombez sur l'une d'elles, ce n'est pas une panne.

| Fonction | Où | État |
|---|---|---|
| **Expertises** | Menu principal | La page indique « Objets de recherche : implémentation en cours » |
| **Domaines** | Fiche d'une publication | L'onglet indique « Domaines de recherche : implémentation en cours » |
| **Mettre à jour dans HAL** | Fiche d'une publication | Fonction en cours de développement : l'onglet n'apparaît pas |
| **Dissocier**, **Invalider** | Fiche › onglet **Sources** › **Actions** | Présents dans le menu, mais sans effet : une infobulle l'annonce |
| **Afficher les structures fermées** | Structures | Attend les données de cycle de vie des structures |

## À savoir

Votre établissement peut être en avance ou en retard sur la version décrite par cette aide. Les nouveautés de cette
version sont présentées sur l'[accueil](/).
