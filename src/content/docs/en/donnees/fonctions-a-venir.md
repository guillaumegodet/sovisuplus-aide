SoVisu+ moves fast, and some features are announced in the interface before being finished. This page describes their
state in version **1.6.4**. If you come across one of them, it is not an outage.

| Feature | Where | State |
|---|---|---|
| **Expertise** | Main menu | The page says "Research areas : work in progress" |
| **Disciplines** | Publication record | The tab says "Research areas : work in progress" |
| **Update in HAL** | Publication record | Under development: the tab does not appear |
| **Dissociate**, **Invalidate** | Record › **Sources** tab › actions menu | Present in the menu, but with no effect: a tooltip says so |
| **Display old structures** | Structures | Waiting for structure lifecycle data |

## Known limits

This list follows the version documented on the help [home page](/en/): your institution may be ahead of or behind it. The
state of each change is in [What's new](/en/nouveautes/).
