## What it is

Each institution installs and configures its own SoVisu+ instance. Two people can therefore see different screens without
either having a problem. In the guides, these differences are flagged by the **Available on** mention.

## What can vary

| Feature | Depends on |
|---|---|
| Roles given to researchers | The institution's decision: without them, accounts are read-only |
| **Help** button | May lead to this help or to a contact address, or be absent |
| ORCID authentication | The institution's registration with ORCID |
| HAL authentication and deposit | Rights given and a HAL service account |
| **Assistant** | The institution's conversational agent service |
| "Missing identifiers" alert | List of identifiers to monitor |
| Retained contribution roles | See [Contributions and retained roles](/en/donnees/contributions-et-roles-retenus/) |
| SoVisu+ version | The institution's update schedule |

## Nantes Université

State in November 2026, version 1.6.4.

| Feature | State |
|---|---|
| Researchers' rights | **Read-only**: personal roles are not given |
| Editing identifiers | From the institution's directory, not from SoVisu+ |

[Druid](https://druid-aide.guillaumegodet.workers.dev/en/), which has its own help.
