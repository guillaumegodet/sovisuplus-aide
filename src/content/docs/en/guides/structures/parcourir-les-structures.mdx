The **Research structures** page presents the structures sent by the directory.

## Steps

1. Choose a view: **Tree**, **List** or **Hierarchical table**.
2. In the **Tree**, use **Search for a structure…**, **Expand all** or **Collapse all**, then select a structure.
3. Read the details: **Supervising institutions**, **Members**, **Publications**, **Child structures**.
4. **Dashboard** opens the structure as a perspective.
5. **Include external institutions** widens the list, **Reset filters** returns to the initial state.
6. **Export** downloads the displayed list.

## Hide a structure

With the corresponding right, **Hide this structure** removes it from the list, the search and the indicators, along with the
structures that depend only on it. **Show hidden structures** lets you find them again.

## Known limits

- **Publication indicators cover the last 24 months.**
- **A missing or wrongly attached structure** is fixed in the directory: see [Where to fix what](/en/guides/corriger/ou-corriger-quoi/).
- **Display old structures** is not available yet.
