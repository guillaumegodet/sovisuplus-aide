L'**Assistant** répond en langage courant à des questions sur les données de recherche connues du graphe de
connaissances : une personne, une structure, leurs publications.

## Étapes

1. Ouvrez la fenêtre de l'assistant.
2. Écrivez votre question dans **Posez votre question à l'assistant…**, puis cliquez sur **Envoyer**.
3. Lancez un autre sujet avec **Nouvelle conversation**. **Retour aux conversations** retrouve les précédentes.

Quand vous écrivez « je » ou « mes publications », l'assistant comprend qu'il s'agit de vous.

## Limites connues

- **Vérifiez ses réponses.** Il peut se tromper, ou répondre à partir de données incomplètes.
- **Il ne sert pas à corriger** : pour une donnée fausse, voir [Où corriger quoi](/guides/corriger/ou-corriger-quoi/).
- **Il peut être lent ou indisponible** : un message le signale, et **Réessayer** relance la demande.
- **Il n'interroge pas cette aide** : pour une question sur le fonctionnement de SoVisu+, utilisez la recherche en haut de
  cette page.
