La page **Structures de recherche** présente les structures transmises par l'annuaire.

## Étapes

1. Choisissez une vue : **Liste**, **Table hiérarchique** ou **Arborescence**.
2. Dans l'**Arborescence**, utilisez **Rechercher une structure…**, **Tout déplier** ou **Tout replier**, puis sélectionnez une structure.
3. Lisez le détail : **Tutelles**, **Membres**, **Publications**, **Structures rattachées**.
4. **Tableau de bord** ouvre la structure comme perspective.
5. **Inclure les établissements externes** élargit la liste, **Réinitialiser les filtres** revient à l'état initial.
6. **Exporter** télécharge la liste affichée.

## Masquer une structure

Avec le droit correspondant, **Masquer cette structure** la retire de la liste, de la recherche et des indicateurs, ainsi
que les structures qui ne dépendent que d'elle. **Afficher les structures masquées** permet de les retrouver.

## Limites connues

- **Les indicateurs de publication portent sur les 24 derniers mois.**
- **Une structure manquante ou mal rattachée** se corrige dans l'annuaire : voir [Où corriger quoi](/guides/corriger/ou-corriger-quoi/).
- **Afficher les structures fermées** n'est pas encore disponible.
