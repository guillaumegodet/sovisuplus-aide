## Étapes

1. Ouvrez une structure, par exemple dans l'**Arborescence**.
2. Lisez la liste **Membres** : **Nom**, **Emploi**, **Arrivée**, **Départ**, **Publications**, **Identifiants**.
3. **Actuellement présents**, activé par défaut, limite la liste aux personnes présentes : désactivez-le pour voir les anciens membres.
4. **Voir les publications de cette personne** ouvre ses publications.
5. Avec le droit correspondant, **Modifier le compte** ouvre son profil.

## Limites connues

- **La liste vient de l'annuaire** : un membre absent ou une date fausse s'y corrige. Voir [Où corriger quoi](/guides/corriger/ou-corriger-quoi/).
- **Les membres d'un établissement** sont ses employés, alors que ses publications passent par ses unités de recherche : les deux chiffres ne portent pas sur les mêmes personnes.
