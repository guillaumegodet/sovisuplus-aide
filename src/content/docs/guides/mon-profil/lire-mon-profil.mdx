Votre profil montre ce que SoVisu+ sait de vous. C'est ce qui détermine les publications retrouvées et les structures
où vous apparaissez : vérifiez-le à votre première visite.

## Ce que contient la page

**Mes identifiants**

- **IdRef**, **HAL** et **ORCID**, chacun avec ce que le service dit de vous : **Informations IdRef**, **Auteur HAL**,
  **Fiche ORCID**.
- **Copier** place un identifiant dans le presse-papiers.

**Mes affiliations**

- **Unité de recherche** : vos unités, ou « Pas de unité(s) de recherche associée(s) ».
- **Ma signature** : la forme de votre nom et de votre affiliation, à copier pour vos publications. Sans donnée, la
  page indique « Aucune signature ».

## Limites connues

- **Consulter ne suffit pas à corriger.** Voir [Signaler une erreur de profil](/guides/mon-profil/signaler-une-erreur-de-profil/).
- **L'identifiant Scopus n'est pas affiché** ici, même s'il est connu de SoVisu+.
- **Votre profil ne montre pas vos droits** : voir [Rôles et droits](/donnees/roles-et-droits/).
- **Autres comptes** : avec un droit élargi, vous pouvez consulter le profil d'une autre personne. La page s'intitule alors **Profil**.
